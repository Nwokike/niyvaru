# Implementation Plan: Niyvaru Integrated Narrative Map, Brand Homepage, Walk HUD & Resilience

## Context & Motivation
Following deep research into the original brand site (niyvaru.eu), the Lisbon reference implementation (*City in Relief / Sete Colinas*), and the Kiri Gateway backend architecture, the app needs five core UX and engineering refinements:

1. **Homepage Brand Layout & Broken Asset Fix**: The current homepage displays a single top image that breaks with a 404 on GitHub Pages (`nwokike.github.io/niyvaru/`) due to missing `BASE_URL` routing. Furthermore, the real `niyvaru.eu` uses an editorial two-column layout over warm paper with a soft Clock Tower watermark background, value prop badges, and a glass request card.
2. **Integrated "Discover" Dossier (Stepping through Places & Stories)**: Rather than isolating places, stories, and the map behind disconnected sidebar tabs, places and their stories/photographs will be unified into an interactive Discover Dossier with `[← Prev]` and `[Next →]` stepping controls (and keyboard arrows) that fly the 3D camera smoothly across the terrain and buildings to each spot, matching *City in Relief*.
3. **"Happening" (Integrated Live Pulse)**: Renaming "Now" to "Happening", featuring an ambient map status bar (weather, active prayer, lighting phase) and an integrated stream of live social posts (Mastodon/Bluesky), weather, and traveller notes.
4. **Non-Blocking 3D Walk HUD**: Replacing the opaque full-screen black scrim (`.walk-overlay { background: var(--ink) }` + `.walk-scrim`) that currently blinds the 3D map with an integrated flying camera and a floating Picture-in-Picture street-photo viewfinder HUD.
5. **AI Gateway Resilience (Pruning ONLY on HTTP 500 / Exhausted Models)**: Preserving full 256k-capable model intelligence upfront without aggressive context pruning, but adding a transparent fallback in `gatewayFetch` that prunes bulky intermediate tool results and retries once if the backend returns HTTP 500 ("All models exhausted").

## Proposed Changes

### 1. Brand Homepage Layout & Asset Path Fix (`src/ui/Intake.tsx`, `src/styles.css`)
- **Fix asset resolution**: Use `import.meta.env.BASE_URL + "brand/..."` for all static brand assets (`hero-makkah.png`, etc.) so they resolve on both local dev (`/`) and GitHub Pages (`/niyvaru/`).
- **Two-Column Editorial Hero Layout** (matching Image 3 from `niyvaru.eu`):
  - **Watermark Background**: Softly faded Clock Tower illustration watermark in the background (`${BASE_URL}brand/hero-makkah.png` with low opacity and blur filter).
  - **Left Column (Hero Narrative)**:
    - Eyebrow: `Private Umrah hotel concierge · Makkah & Madinah`
    - Display H1: `Five-Star Makkah & Madinah Hotels.` `<span class="italic text-bronze-deep">Wholesale rates you can’t get on Booking.com.</span>`
    - Value props: `Your stay, privately · Never a group tour`, `50/50 savings · Below public retail`, `Within 24 hours · Proposal on WhatsApp`.
  - **Right Column (Concierge Request Card)**:
    - Rounded glass card (`Tell us what you need`) with steps 1 & 2, dates, steppers, accessibility toggles, and the city search/selector.
  - Fully responsive: Stacks into a clean single column on mobile screens.

### 2. Discover Dossier & Place Carousel (`src/ui/DiscoverDossier.tsx`, `src/App.tsx`, `src/styles.css`)
- **Curated Discover List**:
  - Filter places with stories (`p.story`), photos (`p.photos.length > 0`), or matching the active category filter (Hotels, Worship, Food, Pharmacy, etc.).
- **Dossier Card Component**:
  - Index display: `01 / 12 · THE KAABA` (or `03 / 15 · HILTON SUITES`).
  - High-resolution photograph from Wikimedia Commons / Panoramax with attribution badge.
  - Wikipedia narrative extract and history snippet.
  - Distance from area center / current location, opening hours status, and accessibility tags (wheelchair step-free).
  - Actions: `[🚶 Walk there]` and `[Ask Concierge]`.
  - Navigation: `[← Prev]` and `[Next →]` buttons, touch swipe, and keyboard arrow keys (`ArrowLeft` / `ArrowRight`).
- **Map Synchronization**:
  - Stepping Next/Prev calls `map.focusPlace(place)` and flies the camera to the coordinate (`map.flyTo({ center: [lon, lat], pitch: 55, bearing: -15, duration: 1800 })`).
  - Highlights the 3D pin on the map.
  - Clicking any pin on the map directly selects that place and updates the dossier card.

### 3. "Happening" Live Pulse HUD & Stream (`src/ui/PulsePanel.tsx`, `src/App.tsx`)
- Rename the tab from "Now" to "Happening".
- Add an ambient status pill to the topbar / map view: e.g. `🌤 27°C · Asr 15:15 · 🌙 Golden hour`.
- Streamline the feed cards with clear source tags (Mastodon, Bluesky, Weather, Prayer, Local), timestamps, and clickable links to locations.

### 4. Non-Blocking 3D Walk Experience (`src/walk/player.ts`, `src/styles.css`)
- **Remove screen-blocking elements**: Remove `background: var(--ink)` and `.walk-scrim` from the root overlay.
- **Persistent 3D Canvas**: The MapLibre map remains fully visible, smoothly animating the camera along the road coordinates in 3D (pitch 60°, following road heading).
- **Floating Viewfinder HUD Card**:
  - Positioned at the bottom of the screen (or bottom-right).
  - Shows street-level photography smoothly crossfading between frames as the camera moves along the route.
  - Progress indicator: `Walk to Al Taysir Street · 450 m of 1,200 m (38%) · ~5 min remaining`.
  - Simple `[Pause]` / `[Resume]` and `[✕ Exit Walk]` controls.

### 5. AI Gateway Transparent Retry on HTTP 500 (`src/agent/gateway.ts`)
- **Keep full context by default**: Do not aggressively prune messages or limit facts upfront, maintaining maximum intelligence for large-context models (e.g. NVIDIA up to 256k).
- **Error Interception**:
  - In `gatewayFetch`, if the response returns `HTTP 500` or JSON with `"error": "All models exhausted"`:
  - Check if the request body contains messages. If so, create a pruned version using a compact strategy (keeping system prompt, initial user request, and the last 2 conversation turns, stripping intermediate tool results).
  - Re-issue the POST request once with the compacted payload.
  - If successful, return the valid response transparently without breaking the conversation.
